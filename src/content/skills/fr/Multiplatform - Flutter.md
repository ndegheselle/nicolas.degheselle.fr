Boîte à outils UI open-source pour créer des applications compilées en natif pour le mobile, le web et le desktop depuis une seule base de code.

- La définition des interfaces est assez verbeuse (éléments enfants imbriqués) comparée à une définition UI en XML comme le HTML
- Pas vraiment fan du fait qu'il soit très facile de mélanger la logique et l'UI
- Ces deux problèmes peuvent être atténués en découpant tout en widgets plus petits
- Les messages de debug sont plutôt clairs, même s'il est parfois difficile d'en trouver l'origine

Globalement plutôt convaincu. Les animations et les données réactives sont vraiment simples, et les performances sont bonnes.
