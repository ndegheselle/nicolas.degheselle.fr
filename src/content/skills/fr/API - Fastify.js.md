Framework web très performant et léger pour Node.js, conçu pour construire des APIs rapides et scalables en mettant l'accent sur la vitesse, l'efficacité et la productivité du développeur. Excellente alternative à Express.js.

## Retour d'expérience

- Aucun moyen simple de générer des schémas OpenApi depuis les modèles ou les classes DTO.
- L'autoload entre en conflit avec les imports TypeScript une fois compilé en JavaScript (il existe probablement des moyens de contourner ça).
