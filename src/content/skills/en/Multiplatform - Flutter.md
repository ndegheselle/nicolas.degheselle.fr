Open-source UI toolkit for building natively compiled applications for mobile, web, and desktop from a single codebase.

- Interface definition is pretty verbose (nested child elments) compare to XML ui definition like HTML
- Not realy fan of the fact that it's really easy to mix logic and UI
- Both of these issues can be mittigated but separating everything in smaller widgets
- Debug message are pretty clear, even if sometimes it's hard to find the origin

Overall pretty fan. Animations and reactive data is really easy, performances are good.
