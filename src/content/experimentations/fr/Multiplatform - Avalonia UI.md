Framework UI .NET multiplateforme et open-source qui permet de créer des applications desktop modernes et réactives pour Windows, macOS et Linux.

## Retour d'expérience

- Bien meilleure gestion des styles que WPF.
- Pas de bonne bibliothèque pour le mobile (ce qui est compréhensible puisque ce n'est pas la cible principale d'Avalonia).
- La plupart des bibliothèques ne sont pas à jour avec Avalonia 12, ce qui est pénible vu le nombre de changements cassants.
