Framework open-source basé sur Vue.js, conçu pour créer des applications web rendues côté serveur (SSR) ou générées statiquement.

## Retour d'expérience

- Le SSR est imposé — inutile pour de simples SPA.
- Le SSR ajoute de la complexité dans la gestion de l'état entre serveur et client (attention à l'authentification).
- Les imports automatiques sont pratiques mais imposent une structure de dossiers rigide (pas d'imbrication).
